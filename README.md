# Анімації курсу «Фізика за методом Феймана» (підготовка до НМТ)

Manim-анімації для YouTube-курсу Іллі Андрійовича Наконечного. Кожна анімація — окремий файл зі сценою, фізика рахується кодом, а не малюється на око.

**Стан:** Лекція 1 (випуски 1.1–1.3) — 16 анімацій, погоджено 19.10.2026. Реєстр зі статусами, синхроном зі сценарієм і рішеннями — [`lecture-01/plan.md`](lecture-01/plan.md).

## Що де лежить

| Шлях | Що це |
|---|---|
| `style/feynman_style.py` | спільний стиль для всіх розділів: палітра (одна величина — один колір), мінімальні розміри зі стандарту читабельності, хелпери `T`, `L`, `M`, `MP`, `vec`, `scale_note` |
| `lecture-01/aNN_*.py` | одна анімація = один рядок розкадровки, клас `A<№>_<Суть>` |
| `lecture-01/calc_1.py` | усі числа для анімацій; `python calc_1.py` друкує таблицю для фактчеку |
| `lecture-01/render.sh` | рендер: чернетка, фінал із прозорим фоном, контрольний аркуш |
| `lecture-01/qa.py` | контроль читабельності: аркуш кадрів у 360p і лінтер дрібних шрифтів |
| `lecture-01/preview.sh`, `lecture-01/preview/` | прев'ю на тлі курсу (H.264) — для перегляду на телефоні |

Фінальні файли для монтажу (`lecture-01/final/*.mov`, ProRes 4444 з альфа-каналом, 105–150 МБ кожен) у git не зберігаються: GitHub не приймає файли понад 100 МБ. Вони відтворюються з коду однією командою (нижче).

## Формат виводу

1920×1080, 25 к/с, прозорий фон. Під текстом — тонкий темний контур, щоб підписи читалися і поверх тла курсу, і поверх живого відео. Мінімуми: текст 28 (основний 36), формули 44–48, смислові лінії від 3. Повний стандарт — у документі «Стандарт читабельності графіки в кадрі».

## Встановлення (macOS)

```sh
brew install ffmpeg cairo pango pkgconf
brew install --cask font-dejavu
# TeX Live з пакетами T2A і babel-ukrainian — для кирилиці у формулах
python3.12 -m venv .venv-manim
.venv-manim/bin/pip install -r requirements.txt
```

`render.sh` шукає venv у `VENV` (за замовчуванням — `~/Desktop/abitly_project/.venv-manim`), інакше бере `manim` із PATH.

## Рендер

```sh
cd lecture-01
./render.sh draft a12_trapezoid_cut.py A12_TrapezoidCut   # 480p15 — рух і таймінг
./render.sh final a12_trapezoid_cut.py A12_TrapezoidCut   # 1080p25, прозорий фон → final/anim_1_12_A12_TrapezoidCut_v1.mov
./render.sh qa    a12_trapezoid_cut.py A12_TrapezoidCut   # final + qa/A12_TrapezoidCut.png
./preview.sh                                              # прев'ю → preview/*.mp4
python qa.py --lint a12_trapezoid_cut.py                  # шрифти < 28, тонкі лінії, сірий текст
```

Субтитри до кожної сцени manim пише поруч із відео: `media/videos/<файл>/1080p25/<Клас>.srt`.

## Як додати анімацію

1. Рядок у `plan.md`: що бачить глядач, на яку фразу синхрон, тривалість.
2. Числа — у `calc_N.py`, не в сцені.
3. Сцена в `aNN_<назва>.py`, підключення стилю — як у `a12_trapezoid_cut.py`.
4. `qa.py --lint` → 0 зауважень; `./render.sh qa …` → переглянути аркуш; виправляти, доки все читається в 360p.
5. Фінал іде в монтаж після погодження Іллею Андрійовичем.
